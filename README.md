# MAD Ecommerce

A basic Android ecommerce application written in Kotlin with Jetpack Compose.

## Features

- Product catalog with category filters and search
- Product detail screen
- Add-to-cart flow
- Cart management with quantity controls and order summary

## Tech stack

- Kotlin
- Android SDK
- Jetpack Compose
- Navigation Compose
- Material 3

## Project structure

- `app/src/main/java/com/example/madecommerce/data`: sample models and repository
- `app/src/main/java/com/example/madecommerce/ui`: screens, navigation, and view model
- `app/src/main/java/com/example/madecommerce/ui/theme`: Compose theme

## Run locally

1. Open `S:\Code\MAD-App` in Android Studio.
2. Let Gradle sync the project.
3. Run the `app` configuration on an emulator or Android device.

This project uses local sample data, so no API setup is required.
